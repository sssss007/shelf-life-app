# 保质期管家 Pro Max

**当前版本：1.9.12（布局自适应 + 安全区版：切页零重建 · dock 自适应留白 · 状态栏安全区 · 毛玻璃 dock）**

一个面向手机浏览器、GitHub Pages 和 Android WebView的本地商品保质期管理工具。

## 功能

- 商品保质期管理（支持按天 / 按月双单位计算）
- 按月计算保质期：直接对年月做加减，正确处理 31号→30号、2月闰日等边界
- 临期 / 过期提醒，三态区分
- 商品分类、搜索与统计
- 存放位置统计
- 条形码拍照识别
- 本地条码记忆库
- 跨设备文本同步
- JSON 数据备份与恢复
- PWA / GitHub Pages 支持
- Service Worker 离线缓存
- 数据使用 `localStorage` 保存，不依赖服务器数据库

## 修复汇总（v1.6 包含以下全部修复）

### 显示与交互

- **弹窗内容可滚动**：录入/编辑弹窗的内容区恒定 `overflow-y:auto` + `min-height:0`，按钮区 `flex:0 0 auto` 不被压缩 —— 修掉「永久删除此物品 / 关闭」在小屏或长表单下显示不全的问题。
- **弹窗高度跟随可视视口**：`max-height` 使用 `--app-height`（由 `visualViewport` 实时维护），键盘弹起也不会把按钮顶出屏幕。
- **吸顶搜索栏改为进度插值渐显**：滚动 0→40px 时背景 / 细线 / 阴影渐显，扫描过阈值不再突变换高度 —— **零 reflow**，观感更自然。
- **统计卡折叠加迟滞**：向下滚过 40px 才折叠、回到 12px 才展开，配合 `overflow-anchor: none` 关掉滚动锚定，消除「点击/滚动时反复抖动」。
- **点按与滚动细节**：`touch-action: manipulation`、`@scroll.passive`、`transition: all` 改为具体属性、清理多余的 `will-change`。

### 数据与持久化

- **归档真正落盘**：所有「已处理 / 恢复」操作改为按 `id` 回写源数组。此前改的是 `processedProducts` 计算属性生成的**副本**，导致列表/归档/统计不刷新、刷新后已归档商品「复活」。
- **自动持久化**：`watch(products, saveData, { deep: true })`，源数据任何改动自动写入 `localStorage`（注册在数据加载之后，避免异常时把空数据回写）。
- **PWA 图标补齐**：新增 `icon-192.png` / `icon-512.png`，并写入 `manifest.json` 的 `icons`。此前 HTML 中引用的这两个文件并不存在（404）。
- **全容器隐藏滚动条**：移动端本来隐藏，桌面宽度下会因列表高度变化闪现滚动条、挤压内容宽度造成抖动；现在所有容器统一隐藏并预留槽位（`scrollbar-width` / `scrollbar-gutter`）。
- **滚动方向感应**：搜索栏 + 分类栏向下滑收起、向上滑 / 回顶 / 到底恢复；底部 dock 向下滑收起后**停手 250ms 自动回来**（常量 `DOCK_SHOW_DELAY_MS` 可调，设 0 则只在上滑时恢复）。
- **修复挂载失败**：修正吸顶搜索栏开标签未闭合（缺 `:style="{\'--stuck\': stuckProgress }">`）导致 Vue 模板编译报错、页面一直停在加载层的问题。

## 屏幕适配（基线）

- 兼容旧机型：为 `100dvh` / `100svh` 增加 `100vh` fallback，避免老 WebView 高度错乱。
- 全面屏安全区：适配刘海屏、灵动岛、Android 挖孔屏，Header 与底部 Dock 自动避开状态栏和手势条。
- 安卓输入法：通过 `visualViewport` 动态修正可视高度，避免键盘弹起时布局跳动。
- 弹窗高度：兼容不支持动态视口单位的旧浏览器。
- iOS 输入放大：将输入框字号兜底为 `16px`，避免 iOS Safari 聚焦时自动放大页面。
- 超小屏：宽度 ≤ 380px 时自动隐藏 Header 按钮文字，只保留图标，防止挤压。

## 加载性能优化

- Service Worker 不再把 CDN 资源放入安装阶段的硬性预缓存，避免某个 CDN 抽风导致 PWA 安装失败。
- 本地资源优先缓存，CDN 资源改为运行时“缓存优先 + 后台更新”。
- 建议将 Vue、Tailwind、Quagga2 改为本地构建或本地文件，以彻底消除首屏对 CDN 的依赖。
- Quagga2 体积较大，建议按需加载（在用户第一次扫码时才动态载入），而不是页面启动时就下载。

```js
const CACHE_VERSION = 'expiry-manager-v1.9.8-smoothswitch-20260919-1';
```

策略：

- 页面导航：网络优先，失败时回退缓存的 `index.html`
- 本地静态资源：缓存优先 + 后台更新

## PWA

- `manifest.json` 已声明 `icons`（192×192 / 512×512），并保留 `display: standalone`、`theme_color: #007AFF` 等字段。
- 当前两个图标是由脚本生成的**占位图**（蓝紫渐变 + “保”字），可直接用同名 PNG 替换（保持 192 / 512 尺寸即可，注意留出约 10% 安全边距）。

## 已知限制与后续建议

- 首次加载仍依赖 CDN，网络较差时首屏会慢；建议将 Vue / Tailwind / Quagga2 改为本地文件或使用构建工具打包。
- Tailwind CDN 是运行时扫描页面生成样式，在低端机上有一定性能开销；如追求极致流畅，可改为预编译 Tailwind CSS。
- 吸顶栏与弹窗已刻意避开 `backdrop-filter`（低端机上滚动时逐帧重绘代价高），如后续想上毛玻璃，建议只在高端设备上按 `@supports` 条件启用。
- Quagga2 条形码识别属于重型计算，建议在低端机提示用户“保持稳定、光线充足”。
- 数据保存在 `localStorage`，不建议存放超大容量；请定期导出 JSON 备份。

## 本地数据
